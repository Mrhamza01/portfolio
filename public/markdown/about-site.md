# About This Site

This portfolio is a macOS-inspired desktop experience built with **React**, **Vite**, **Zustand**, and **UnoCSS**, deployed on **Vercel**.

It showcases **Hamza Ghafoor** — Full Stack Software Engineer focused on full-stack product engineering, backend/async systems, marketplace payments, and cloud-native (including air-gapped on-prem) delivery.

Features include live widgets (weather, news, exchange rates), AI chat, Siri-style voice assistant, architecture case studies, and interactive “About This Mac” / App Store views of skills and experience.
