# Hamza Ghafoor — Portfolio

Live: https://hamzaghafoor.vercel.app

One site, three entry points (a Vite multi-page build):

| Route | What it is | Source |
| --- | --- | --- |
| `/` | Portfolio chooser: new or previous portfolio | `index.html`, `src/selector/` |
| `/journey/` | New scroll-driven portfolio (React, three.js, Lenis) | `journey/index.html`, `src/journey/` |
| `/classic/` | Previous macOS-style portfolio, preserved as it was | `classic/index.html`, `src/` (everything outside `journey/` and `selector/`) |

The static SEO pages (`/about/`, `/experience/`, `/projects/`, `/case-studies/`, `/skills/`) are generated by `scripts/generate-seo.mjs`.

## Develop

```bash
pnpm install
pnpm dev      # http://localhost:5173/
pnpm build    # regenerates SEO files, then builds to dist/
```

## Editing content

- New portfolio copy: `src/journey/content.ts`. Every claim there traces back to `src/configs/profile.ts`, `src/configs/caseStudies.ts` or the resume. Keep it that way.
- Classic portfolio and SEO pages: `src/configs/profile.ts` and `scripts/seo-data.mjs`.

## Resume

The resume source is LaTeX: `resume/hamza-ghafoor-resume.tex` (single column, text only, ATS-friendly).

```bash
pnpm resume   # needs pdflatex; compiles and writes public/resume.pdf
```
